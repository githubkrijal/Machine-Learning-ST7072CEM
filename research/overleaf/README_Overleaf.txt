Overleaf project

1. In Overleaf choose New Project > Upload Project.
2. Upload Nepal_Forest_Fire_Overleaf_Project.zip.
3. Open main.tex and select pdfLaTeX if it is not chosen automatically.
4. Recompile. The project uses the two-column IEEE conference layout, author-date citations, APA 7 reference entries, the included colour figures, and an appendix with a VS Code capture and source excerpts.

The manuscript analyses 218 forest-containing grid cells with complete daily weather histories and 348,582 cell-days. Its scope and limitations are stated in the paper, including the earlier exploratory use of overlapping 2016 labels. The reported results describe the analysed sample and should not be presented as validated national coverage or operational performance.

Balanced accuracy is the main percentage comparison (68.31–74.64%). Ordinary accuracy is a separate metric and remains explicitly labelled in the body. Results have not been changed to meet a preferred percentage. Add your GitHub repository URL in the appendix.
